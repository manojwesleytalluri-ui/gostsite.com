# Happy Birthday, Pottiii! 🎂💜

A special, interactive birthday website featuring memories, butterflies mini-game, animations, music, and personalized wishes.

## ✨ Features
- ⏳ Real-time countdown to the birthday
- 🦋 Interactive butterfly-catching game
- 📸 Photo memory cards with responsive layout
- ✍️ Typewriter appreciation message
- 🎭 Fun personality cards with bouncy animations
- 🎂 Birthday reveal with floating confetti
- 💌 Personal letter & friendship credits

## 🚀 Live Demo
Open `index.html` in any modern web browser or serve locally.
